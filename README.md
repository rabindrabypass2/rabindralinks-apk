# RabindraLinks - Task & Games Reward App

An Android Task & Games application featuring Brain Quiz, Memory Tile Puzzle, Speed Math Sprint, and Daily Rewards, monetized with Unity Ads.

## Features
- **Unity Ads Integration:**
  - Game ID: `800446112`
  - Banner: `BP_Banner_Android`
  - Interstitial: `BP_Interstitial_Android`
  - Rewarded: `BP_Rewarded_Android`
- **Mini-Games & Tasks:**
  - ❓ **Brain Quiz Challenge:** GK, science & tech questions with instant scoring.
  - 🧩 **Memory Tile Puzzle:** 12-card emoji matching puzzle with 2X bonus reward.
  - ⚡ **Speed Math Sprint:** Rapid arithmetic against a 30s countdown.
  - 🎬 **Mega Video Task:** Direct rewarded sponsor video for points.
  - 🎁 **Daily Check-In:** 24-hour streak rewards.
- **Wallet & Redemption:**
  - Real-time balance updates and persistent storage.
  - Redeem points dialog (UPI / bKash / PayPal).

## Automated CI/CD
Every push triggers GitHub Actions to automatically build and release the Android `.apk`.
